# Marvel Advisors wazuh-dev Kubernetes



Deploy a Wazuh cluster with a basic indexer and dashboard stack on Kubernetes.

## Branches

* `main-dev is the branch where you should work using this repo, the master branch contains  
the default wazuh, and not the one we use for Rise Broadband. There you can see all the steps for  
deploying wazuh. `
